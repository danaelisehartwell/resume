# Dana Hartwell — Portfolio

Personal portfolio and resume website.

🌐 **Live site:** [danahartwell.com](https://danaelisehartwell.github.io/resume/)

## Features
- Responsive design with mobile hamburger navigation
- Scroll reveal animations
- Rotating fun facts
- Downloadable CV

## Built with
- HTML, CSS, Vanilla JavaScript
- Fonts: Cormorant Garamond, DM Mono (Google Fonts)

## Run locally
Download `index.html` and open it in any browser — no setup needed.
